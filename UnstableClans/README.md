# UnstableClans

Clan system for UnstableSMP.

## Commands
- `/clan create <name>`
- `/clan invite <player>`
- `/clan accept`
- `/clan leave`
- `/clan kick <player>`
- `/clan home`
- `/clan sethome`
- `/clan chat <message>`

## Features
- Leader, members, ranks (extendable)
- Clan home with teleport
- Clan chat
- Invites
- PvP settings (configurable)
- Data persistence ready

## Permissions
- unstable.clans.use
- unstable.clans.admin
