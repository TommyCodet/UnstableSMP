# UnstableMessages

Advanced messaging plugin for UnstableSMP.

## Features
- MiniMessage support for rich text
- Action bars
- Titles & Subtitles
- Configurable sounds
- Integration with UnstableCore
- Reloadable messages

## Installation
1. Install UnstableCore first.
2. Place UnstableMessages.jar in plugins/.
3. Restart server.
4. Edit plugins/UnstableMessages/config.yml for custom messages.

## Commands
- `/umessages reload` - Reload messages (permission: unstable.messages.admin)

## Permissions
- unstable.messages.admin - Admin commands
- unstable.messages.use - Basic use (default true)
