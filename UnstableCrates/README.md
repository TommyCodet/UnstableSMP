# UnstableCrates

Crate and Key system for UnstableSMP.

## Crates
1. **Building** - Shulkers with blocks, redstone or wool
2. **Creator Kits** - Random editable creator kits (FlameFrags, Wemmbu, etc.)
3. **Equipment** - Select totems, rockets, pearls, apples, crystals...
4. **Netherite & Elytra** - Armor pieces, tools or Elytra
5. **Special** - Maces, Tridents with enchantments

## Commands
- `/crate give <player> <crate>` - Give key
- `/crate key give <player> <crate> <amount>` - Give keys
- `/crate edit <crate>` - Open edit GUI (admin)
- `/crate reload` - Reload config

## Features
- Key requirement to open
- Anti-dupe via custom model data / PDC
- Admin GUI for placing rewards
- Persistent storage (extend with SQLite)
- Compatible with UnstableCore

## Permissions
- unstable.crates.admin
- unstable.crates.use
